# Phase 5: Run and Stabilize

## Core Responsibilities

- Execute the generated specs when that is possible
- Report honestly when it is not

## Workflow Steps

### Step 1: Decide Whether to Run

Run only when ALL of these hold:

1. A framework profile exists with `reviewed: true` and a `run_command`
2. The generated specs were placed in the host repository in Phase 4
3. `npx playwright --version` succeeds in `playwright_project_root`

If any fails, report **SKIP — generated specs not executed** with the reason, and stop. Never
claim a generated suite passes when it was never run.

### Step 2: Run the Generated Specs

Run only the specs generated by this command, never the whole suite:

```bash
cd "{playwright_project_root}" && {run_command} {generated_spec_paths} --retries=0 --workers=1
```

Retries disabled and a single worker keep the diagnosis clean.

### Step 3: Triage Failures

For each failure, classify it using `## Failure Classification` in
`@agent-qa/rules/automation-conventions.md`.

| Class | Action here |
|-------|-------------|
| Selector | Re-derive from the exploration snapshots and fix, if the gate in Phase 4 allowed source edits |
| Synchronization | Add the observable wait recorded in the exploration report |
| Real defect | STOP. Report it. The generated test found a genuine bug |
| Test data, environment, flake | STOP. Hand off to `/agent-qa:debug-tests` |

Apply only fixes listed under `## Allowed Fixes`. Never apply anything under
`## Never-Apply Fixes` to make a generated test pass.

### Step 4: Confirm Stability

For specs that now pass, re-run them `automation.stability_runs` times. A spec that does not pass
every run is reported as unstable, not as passing.

### Step 5: Report

Append a `## Execution` section to the run summary: specs run, passed, failed with their
classification, fixes applied, and any spec still unstable.

## Data Storage

- `execution_results`: per spec — passed, failed with class, or skipped
- `fixes_applied`

## Constraints

- Never run the host repository's full suite
- Never modify a test to hide a real defect
- Never report a spec as passing without the configured stability runs
- Never edit `playwright.config.ts`
