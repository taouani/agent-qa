A `document` workflow writes QA documents on one engine, starting with the test plan: from a Jira key, a JQL filter, an earlier requirements run or a reviewed test-cases run. Agent-QA checks every issue is covered once and every masked value comes from the sources, you review it by changing or removing texts, and it is kept as `document@1` (`document.md`). See docs/documents.md.
