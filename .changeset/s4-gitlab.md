GitLab is a git host: `git.platform: gitlab` opens the CI pull request as a merge request (a draft by a `Draft:` title), and reads the merge requests that name an issue key, with their diffs, for `withPullRequests`. GitLab.com by default, or a self-managed `baseUrl` ending in `/api/v4`. In GitLab CI the merge request goes into the job's branch, and the token is sent only to `CI_API_V4_URL`.
