`scripts` now ends with a review: you see every generated file whole, with the notes and the type check result, and on your own yes Agent-QA writes them to the repo through the policy layer (`policy.writes.testCode`). Files are only created, never replaced, all or none; `scripts-written@1` records what was written. In CI nothing is written (the pull request comes with the GitHub adapter). The files go only to the folder you were asked about, and only the draft you were shown: a profile saved since, or a draft changed in the run folder, writes nothing. A file that already holds exactly the generated bytes counts as written, so a write that stopped halfway can run again. File names Windows can't write as given (`:`, `CON`, a trailing dot) and new root tool configs (`*.config.js`, `.pnpmfile.cjs`) are refused.
