A fresh install is quicker to get right. `agent-qa init` asks in a terminal for the Jira site (`acme` is enough) and the Xray project key, instead of writing a placeholder site. It ends with the exact variables to set, in your shell's syntax. `doctor` names a placeholder site left in `agent-qa.yaml`, and reports a timeout through a proxy as a timeout. New guide: docs/getting-started.md, including Windows and company-network notes.
